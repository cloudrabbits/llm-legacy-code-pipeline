# 模块 Orders

Orders模块实现超市订单管理核心业务，采用经典三层架构。表现层由OrdersServlet承接请求并转发至JSP视图（如billAdd.jsp等），提供新增、修改、删除与详情页渲染；业务层通过OrdersBiz/Impl封装分页、模糊查询及事务控制；数据访问层依托OrdersDao/Impl操作orders、goods及orders_view表。实体设计包含Orders、OrdersDetail、OrdersView及Suppliers，支撑订单明细与供应商关联展示。模块支持完整CRUD流程与前端Ajax动态加载商品/供应商数据。整体架构职责清晰，但基于传统JSP+Servlet模式，前后端耦合较深，且未引入现代路由框架，依赖直连跳转。
