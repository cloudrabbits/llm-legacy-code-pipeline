## 任务：鉴权与会话链路

【输入范围】`src/main/java/com/zy/Filter/LoginFilter.java`、`servlet/LoginServlet.java`、
`servlet/AuthImage.java`、`utils/Md5.java`、`utils/VerifyCodeUtils.java`。

【方法】
1. 梳理登录流程：表单 → LoginServlet → DAO 校验 → Session 写入键名。
2. 梳理验证码：生成（AuthImage/VerifyCodeUtils）→ 存入 Session 的键名 → 校验位置 → 是否失效。
3. 梳理 LoginFilter 的放行规则（哪些 URL 免登录、未登录跳转目标）。
4. 判定越权风险：是否有角色/权限维度、是否仅靠 Session 键存在性判断、是否存在可直接访问的 URL。

## 越权与会话风险（每条带行号，标注严重程度）
