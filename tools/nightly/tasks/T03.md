## 任务：数据模型与 SQL 映射

【输入范围】`src/main/java/com/zy/bean/*.java`、`src/main/java/com/zy/dao/*.java`、
`library.sql`、`src/main/resources/c3p0-config.xml`。

【方法】
1. 从 `library.sql` 提取表结构（表名、字段、类型、约束、字符集）。
2. 建立 表 ↔ Bean 字段映射，标注类型不一致与命名差异。
3. 逐个 DAO 方法提取 SQL 摘要，标注是否参数化（PreparedStatement vs 字符串拼接）。
4. 标注事务边界（是否显式 commit/rollback、autocommit 状态）。

【产出章节】
## 表结构（来自 library.sql）
## 表-Bean 字段映射表（表 | 列 | 列类型 | Bean字段 | Java类型 | 是否一致）
## DAO 方法 → SQL 对照表（方法 | SQL摘要 | 参数化? | 行号）
## 事务与连接管理现状
## 风险与不一致（每条带 文件:行号）

【约束】SQL 摘要不得臆造；若 SQL 由字符串拼接而成，明确写出"拼接"并给出行号。
