## 任务：Maven 依赖治理

【输入范围】`pom.xml`（15 个依赖），以及依赖在源码中的实际使用位置（可用 grep 类名判断）。

【方法】
1. 逐个依赖给出：用途、在代码中被引用的位置（或"未被引用"）、是否仍需要、风险、建议版本。
2. 重点判定：
   - `junit-jupiter-api` 版本为 `RELEASE`（不可重复构建的元版本）；
   - `maven.compiler.source/target = 1.7` 与 JDK 现状的冲突；
   - `json-lib` 与 `org.json`、`gson` 三者并存（重复能力）；
   - `javax.servlet-api` / `jsp-api` 的 `provided` 范围是否与容器冲突；
   - `mysql-connector-java 5.1.46` 与 MySQL 8 的兼容性。
3. 给出"可删除 / 应升级 / 应锁定版本"三张清单。

【产出章节】
## 依赖总览表（groupId:artifactId | 版本 | scope | 用途 | 引用位置）
## 风险依赖详析（逐个）
## 可删除清单
## 应升级清单（含建议版本）
## 应锁定版本清单

【约束】"未被引用"必须基于 grep 结果，不得凭印象。
